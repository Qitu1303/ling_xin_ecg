# T2 · 案例模板：板上运行/排障报告

- **类型**：案例模板（报告模板）
- **适用场景**：一次板上联调/故障复盘的记录与交接（单人回看、多人接力、跨天排障均适用）。
- **使用方法**：直接复制【模板正文】开写；一页总览表 + 单 bug 分节 + 判别法速查 + 产物索引 + 官方文档对照，五段一个不少。
- **失效条件**：本模板的价值依赖"判别实验"段——只写结论不写判别实验的报告无法被他人复核，等于没写；状态标记若无配套"验证判据"会退化成心情标注。
- **已验证效果**：某次跨天排障复盘按此结构写就后，"待验证项、绕过方案与正解"区分清晰（软件补丁绕过 ≠ 修复），交接零歧义；同结构沉淀 12 份板测记录，均可离线复算。
- **来源**：某显示链联调（四个版本迭代）中"弱判据差点把排查带沟里"的元教训反推而成（反例库见文末）。

## 必须留的机器可读证据（写"环境版本"与"回归判据"两节用）

1. 日志首行 **关键文件 md5sum 三行**（小写 hex + 两空格 + 相对路径）；
2. 启动横幅（case 名 / 注入窗 / 期望输出 / 禁忌码）；
3. 速率标定行（软件实测口径与硬件口径分开写，含投递缺口）；
4. 收尾 stats 全字段（时长 / 样本数 / 各口径速率 / 重标定次数 / 漏投比例 / 区间分位 / 最后错误）；
5. 显示层与插件层的逐组件计数与耗时（帧数/跳过/错误/单次耗时 p50/max）；
6. **事件流逐条** `[序号] 级别 码 描述`。
   注意：某些统计量在特定数据格式下**结构性恒零**（如 12-bit 左对齐码值下"越界比例"物理上不可达）——没有诊断价值的指标别写进结论。

## 三条写作纪律

1. **判别实验块**：寄存器级/单点 dump 不足以定根因。真实反例：某使能位读回为 0 → 怀疑"模块未使能"；手动置位仍无现象 → 嫌疑降级；最终真根因是时钟跨区域偏斜（见 K3 篇）。每条嫌疑必须"预测 → 实验 → 维持/降级"三段齐全。
2. **状态标记**：每条 bug 给状态 + 一行验证判据；"待验证"如实写待验证，混进结论会误导后续排期。
3. **弱判据反例库**（写报告前自查这五条）：
   - 用**字符串存在**当版本判据（hwh 里有某端口名 ≠ 是那一版，两版都含）→ 换 MD5/结构差异；
   - 用**编译通过**当连接正确（`vlog` 只查语法，具名端口连到不存在的端口不报）→ 换 elaborate 级校验或权威 `.veo/.xci` 清单；
   - 用**单点寄存器 dump**定根因 → 换因果链预测 + 判别实验；
   - 用**日志最后一行**反推卡在哪段 → 换分段判据（启动判据见 K1 篇）；
   - 用**文件名/目录名/时间戳**当版本 → 换哈希（板载时钟不可信，见 K1 篇）。

## 预期输出

一份他人可复核的报告：照"回归判据"一节能直接重放；照"判别实验"节能理解为什么是这个根因；照"状态"节能知道哪些已闭环、哪些挂账。

## 来源

某版显示链联调复盘（四个 bit 版本、五大主故障 + 构建期坑）：本轮曾用软件补丁绕过中断登记缺失并验证显示链路可通，报告里显式写"绕过 ≠ 修复，下一版才是正解"；"VTC 未使能"假设被判别实验否掉后降级，主线归到 BUFR 跨区域偏斜并一天内闭环。模板五段结构即该复盘的实际骨架。
